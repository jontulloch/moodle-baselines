# 01 Module Guide Available

The **01 Module Guide Available** report shows the results of the check to see whether a Module Guide has been uploaded into the Welcome & Module Preparation section. The availability of a module guide for students is a standard expectation, and an integral part of the how UEL demonstrates to Higher Education authorities such as the Office for Students (OfS), and the Quality Assurance Agency (QAA) compliance with requirements related to the publication of module-level information. For this reason, even if you are providing module-level information to students in other ways, it remains essential that a current module guide is uploaded to your module page.

In order to ensure a consistent experience for both students and staff, we expect the module guide to be added to the Welcome & Module Preparation section on your Moodle module page. This means that it is easy to know where to look for it.

This detailed report shows whether a module guide has been identified on your course page, and whether that module guide is found in the Welcome & Module Preparation section.

### Appearance

The top of the detailed report table explains the criteria through which the pass / fail result has been achieved on the summary report and the in the progress bar. Below that explanation, there are two columns: One titled ‘section’ and the other ‘resource name’.


![Top of the report](/assets/gitbook/image-13.png)


In the Resource Name column you will see the name of the file or activity that has been identified by the search. The green tick next to the name indicates that it matches the search criteria. In the Section column, you will see the name of the section where the file or resource has been located. If this section is the ‘Welcome & Module Preparation’ section, then a green tick will appear next to the section name. If not, a red cross will appear instead.

### What it does

The search itself scans through the titles of every uploaded file and activity on the course page looking for any that contains the text "module guide", "course guide", or "module handbook". Any file or resource with this text will be considered a Module Guide. Of course this does mean that the search is rather limited, and there is potential for errors. Two in particular:

* **Firstly**, a document titled “This is not a module guide!” will still be counted as a module guide. This is considered a relatively low risk.
* **Secondly**, the search is not able to determine whether the module guide is current or not. If a module guide is out of date, the search will not be able to identify this. This is partly because it is not possible for the search to scan the text inside the document, and partly because there are wide variations in the naming of module guide files - with many of them not including dates in the file name. So, while the search does identify module guides, it is still important for educators to ensure that their module guides are current.

The search does identify if a module guide file is set to be hidden from students - and it will not count hidden files in it's calculations. This means that if a current module guide file is present on the course page, but is hidden from students, the criteria will still be considered as unmet. In such a case this report will display a banner saying ‘Your module guide appears to be hidden from students. You need to have a module guide that is visible to students to meet this standard’.


![Message if standard not met](/assets/gitbook/image-14.png)


The search will also identify what section the file or activity appears in. The module guide is expected to be in the ‘Welcome & Module Preparation’ section. If a module guide is found on the course page, but it is in a different section, then a banner will appear saying ‘Your course page does include a Module Guide, but it is not showing in your ’Welcome & Module Preparation's section. We recommend moving it to this section, as this is where students will be expecting to see it'.


![Message if standard met in wrong section](/assets/gitbook/image-15.png)


### How to use it

The main function of the 01 Module Guide Available detailed report is to provide clear information about why the minimum standard relating to the module guide is showing as either pass, or fail.

If a module guide is present on the course page, is visible to students, and is in the Welcome & Module Preparation section, then the report will look like this:


![The report with a correct resource](/assets/gitbook/image-16.png)


The resource name has a tick next to it, showing that it has been identified as a module guide for the course page.

If the module guide is identified on the course page, and is in the correct section, but has been hidden from students, the report will display an alert banner explaining that you need to make the module guide visible to students in order to meet the minimum standard.


![The report with an incorrect respource](/assets/gitbook/image-17.png)


The section name has a green tick, to show that the file is in the correct section, and the resource name has a green tick to show that it has been identified as a module guide. However the resource name will appear slightly grayed out, and there is a hidden eye icon next to it, indicating that it is hidden. Users can click on the resource name to navigate directly to the file or resource, where they can modify the visibility settings.

If the module guide has been correctly identified, and is visible to students, but is not in the correct section, the resource name has a green tick, showing that it has been identified as the module guide.


![The report with a correct resource in the wrong section](/assets/gitbook/image-19.png)


&#x20;However, the section name has a red cross next to it, showing that the file is not in the correct section. Additionally, a banner appears giving clear information about where the resource or activity needs to be moved in order to meet the minimum standard. Once again, clicking on the resource name will take users directly to the resource, or clicking on the section name will take them directly to the section, where they can move the file or resource.
