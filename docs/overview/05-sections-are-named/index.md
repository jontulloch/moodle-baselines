# 05 Sections are Named

The **05 Sections Named** report checks the course page for any visible sections that have not been given a name, or that still have a generic name.

### Appearance

The top of the detailed report table explains the criteria through which the pass / fail result has been achieved on the summary report and the in the progress bar. Below that explanation, there is a single list of all the sections on the course page, showing which ones are hidden, which have not had the title updated, and which have:


![](/assets/gitbook/image-42.png)


Sections that are hidden from students will appear slightly greyed out, and with a hidden eye icon next to them. These rows will be highlighted in green. Sections that have a name given to them and are visible to students will appear normally, and be highlighted in green. Sections that have not been given a name, and are visible to students, will be highlighted in yellow. They will have a warning icon next to them, and a spanner icon that can be clicked to take users directly to the section for editing.

### What it does

This report searches through the course page and lists all of the sections on the page. It then looks at the section names, and identifies if any have names corresponding with the ‘generic’ names automatically given to new, empty course pages (i.e. ‘New Section’). If a section name does **not** have a generic name, and a new name has been given to it, then it meets the criteria for the minimum standard. The section will show up in the report highlighted in green.


![](/assets/gitbook/image-43.png)


If a section is hidden from students, the it is considered to meet the criteria for the minimum standard whether the name is generic or not. So a section name may not be updated, but if the section is hidden from students it will not impact on their learner experience. In this instance, the section will show highlighted in green, and with a hidden eye icon, indicating that the section is hidden.


![](/assets/gitbook/image-44.png)


If a section has a generic name that has not been updated, and is still visible to students, the section will appear highlighted in yellow, and with an alert icon next to it. The section will also have a spanner icon, which can be clicked to take users directly to the section settings where the name can be changed.


![](/assets/gitbook/image-45.png)


### How to use it

In order to meet the criteria for the minimum standard, the report needs to have no sections highlighted in yellow and with alert icons next to them. These sections can also be identified because the section name will show as “Section name not updated”.


![](/assets/gitbook/image-46.png)


To resolve these issues, users can click on the spanner icon next to the section name. This will take them directly to the editing page for the section, where they can edit the name in the ‘Section name’ field.


![](/assets/gitbook/image-47.png)


Alternatively, they can click on the section name itself which will take them directly to the section on the course main page. From here, they can click on the pencil icon next to the section name. This will enable them to edit the section name directly on the course page. Pressing ‘return’ when finished will same the new section name.


![](/assets/gitbook/image-48.png)
