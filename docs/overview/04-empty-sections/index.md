# 04 Empty sections

The **04 Empty sections** report checks the course page for any visible sections that contain no activities or resources.

## Appearance

The top of the detailed report table explains the criteria through which the pass / fail result has been achieved on the summary report and the in the progress bar. Below that explanation, there are two columns: One titled ‘Instructor’ and the other ‘Log entries’.


![](/assets/gitbook/image-35.png)


The instructor column includes the profile picture associated with the user, the name of the instructor, and an editor icon which can be used to directly access the profile settings. The log entries column shows the number of log entries that user has made on the course over the last two months.

## What it does

This report searches through the course page and lists all of the sections on the page. It then identifies whether any of the sections are empty, and have no content or activities added to them. If a section has content, then it is shown with a green ‘Active’ badge. Be default, sections that include content from the page template should automatically show as active:


![](/assets/gitbook/image-36.png)


If a section is empty, but hidden from students, then the report will show these with a green ‘Hidden’ badge. Again, these sections will be highlighted in green, because there is no action required:


![](/assets/gitbook/image-37.png)


If a section is empty, but is visible to students, then the report will show it with a yellow ‘Empty & Visible’ warning badge, and it will be highlighted in yellow. These are the sections that require action - either in adding content or making the section hidden from students:


![](/assets/gitbook/image-38.png)


## How to use it

The report will highlight in yellow any sections that require action taken to meet the minimum standard. If a section is showing with a yellow highlight, then that section contains no activities or resources and is visible to students. This means students have to scroll past the section to reach any later content, or students may be confused thinking that there is meant to be content that they cannot see.


![](/assets/gitbook/image-39.png)


To fix these empty sections, clicking on the section name will take you to the section itself on the course page. From here, you can switch into Edit Mode and add activities or resources to the section using the + button in the section:


![](/assets/gitbook/image-40.png)


Alternatively, you can click on the three dots to the right of the section name. This will open up a drop-down menu form which you can choose to either **delete** the section, or **hide** it to make it invisible to students:


![](/assets/gitbook/image-41.png)
