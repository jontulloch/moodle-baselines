# The Summary Report


![The summary report](/assets/gitbook/image-10.png)

<p>The summary report gives an overview of what standards have been met</p>


The summary report is accessed from the embedded progress bar on the course page. It lists each of the Minimum Standards together with the check result for each one. The summary report provides an overview of results, and acts as a gateway to more detailed reports that show exactly how each criteria has been met, or what needs to be changed in order to meet them.

## Appearance

The top of the summary table provides a description of the report, and directions on how to use it:


![The report description](/assets/gitbook/image-11.png)

<p>The top of the summary report describes the report contents</p>


The report table lists each of the minimum standards, 1-11, on the left hand side. On the right hand side the result for each standard is displayed. The results for each standard can be:

* **Pass:** Meaning that that criteria for the standard have been met on the course page
* **Fail:** Meaning that the criteria for the standard have not been met on the course page
* **n/a:** Meaning that the minimum standard is not relevant to the module, and is not counted

These results are colour-coded for ease of use: pass results show as green, fail results show as red and n/a results show as grey.

## What it does

The summary report lists each of the Moodle Minimum Standards, and then searches the course page for specific criteria related to each standard. The course page it searches for, is determined by context. If the summary report is opened from within module EX4001, then the report will be searching the EX4001 course page in order to determine results. It is possible to check this using the web address in your web browser. It should look something like this:

> https://moodle.ac.uk/blocks/configurable\_reports/viewreport.php?id=97\&courseid=**84865**

The ID number at the end of this string represents the individual course page. In this instance, **84865** is the unique ID number for the module EX4001. If I were to navigate to the main course page for EX4001, I would see the same number again in the web address:

Each of the minimum standards is evaluated in a different way to achieve the results.


## 01 Module Guide Available


Scans the course page for any activity or file with "module guide", "course guide", or "module handbook" in the title. If one of these is found in the Welcome & Module Preparation section, the result is a pass. Otherwise the result is a fail.


## 02 Is the contact information for the module tutor visible in the blocks drawer?


Checks whether the ‘contact information’ block is present on the course page, and a Primary Instructor is enrolled on the module. If both conditions are met, the result is a pass. Otherwise the result is a fail.


## 03 Does the module tutor have a profile picture so students know who they are?


Looks up the Primary Instructor(s) on the module, and checks to see which of them has been accessing the module most frequently. This instructor is assumed to be the main instructor for the module. It then checks whether this instructor has a profile picture. If they do, the result is a pass. If they have just a generic avatar, the result is a fail.


## 04 Have you made sure to hide or remove empty sections?


Checks the module page to see if there are any sections that are empty and without content. If there are, it then checks to see if those empty sections are visible to students or have been hidden. If there are no empty sections, or if there are empty sections that have been hidden from students, the result is a pass. If there are empty sections that are visible to students, the result is a fail.


## 05 Have you given your visible sections a meaningful name?


Checks to see if there are any sections on the module page that have not been given a specific name. It searches for sections that still have the generic names that are given by default on a blank course. If it identifies these sections, it then checks to see whether those sections are visible to students, or have been hidden. If there are no sections with generic names, or generic sections have been hidden from students, then the result is a pass. If there are generic sections that are visible to students, then the result is a fail.


## 06 Are your activities and resources named in a way that makes sense to students?


Checks the names of all files and activities on the course page, to see if the names are meaningful enough to give students a clear indication of what the resource is. To do this, it looks for names that are too generic (i.e. ‘Presentation’) or obscurely codified (i.e. ‘Ex4001 CW2 100W’), or autogenerated (i.e. ‘95e95a98d0ec.jpg’). If there are no files with names matching these criteria, then the result is a pass. If there are such files, then the result is a fail.


## 07 Have you added module specific careers information in the relevant section?


Checks whether additional content has been added to the Careers & Employability section, other than the default content that is there in the standard UEL module template. If additional content has been added to this section, then the result is a pass. If the Careers & Employability section is empty, or contains only default content, then the result is a fail


## 08 Have you ensured there are no copyright files?


Checks the course specifically for PDF files that may have been downloaded from publisher websites. It looks for PDF files that include DOI patterns, publisher source URLs, citation-like filenames, or year markers. If there are no files matching these criteria, the result is a pass. If files matching these criteria are identified the result is a fail.


## 09 Are summative assessment links available, with completion criteria?


Checks first the course settings for Moodle Minimum Standards. If these settings indicate that students are not submitting their assessments via Moodle, then the result is n/a. If not, it then checks to see if there is an assignment, quiz, Turnitin, or summative-tagged activities in the Assessment and Feedback section. If not, the result is a fail. If there is, it then checks to see if any of those activities have completion criteria added to them. If they do, the result is a pass. If they do not, the result is a fail.


## 10 Are the due dates for your submissions visible on the course page?


Scans the course page for any reference to due dates (e.g. "due on", "submission date", "submit by"). If there is, the result is a pass. If not the result is a fail.


## 11 Checks whether the course includes at least one active learning activity.


Checks whether the Course contains activities with completion criteria added, or contains any activities that require students to interact (i.e. Choice, Feedback, Chat, Checklist, etc.). If there are, the result is a pass. If not the result is a fail.

## How to use it

The summary report gives an overview of whether the specific criteria for the Moodle Minimum Standards have been met. It will often be that this is all users need - if the report indicates a ‘fail’ for whether a module guide has been uploaded, then if the user adds a module guide to the course page this result will automatically change to a ‘pass’. By checking this report, and addressing any failed elements, users can bring their page up to 100% meeting of minimum standards.

Sometimes it is not clear why, or how a result has been reached. You may think that you have met a criteria and wonder why it is showing as ‘fail’. Or a criteria may be showing as ‘pass’ but you are not sure why. In these cases, clicking on the name of the criteria will take you to a detailed report that shows more precisely which activities / sections / content has been identified, together with an explanation of how they relate to the specified criteria.
