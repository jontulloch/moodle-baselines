# 11 At least one active learning activity

This minimum standard requires that at least 1 activity is included on your course page that promotes active online learning. Active Learning has been at the heart of teaching and learning strategies in UEL for many years and continues to be in current strategies and frameworks. For over 100 years, research into teaching and learning has demonstrated that active learning can lead to _improved student performance, lower failure rates, stronger learning gain, improved engagement and participation, improved long-term information retention, reduced attainment gaps, development of higher-order thinking skills_ and _improved attitudes towards learning_.

Including the range of options available in H5P, there are **over 60 activities** that can be added to your course page that promotes active learning. This number increases when completion criteria are added to other activities, requiring student action.

Below that explanation, any activities on the course page that foster active learning are listed. Users see the activity name, activity type, and whether completion criteria have been added:

Underneath this list is a further activities that have not been added to the course page, but that can also foster active online learning.

### What it does

This report checks the course page for any activities that are considered capable of fostering active learning. These activities are comprised of a list of **activities available to be added** to the course page. The course page needs to include **just 1 of these activities** in order to meet the minimum standard - a requirement that reflects the fact that there are inevitably some limitations to these criteria. For example, this list is not able to include any active learning that may be taking place through embedded media, instructional documentation, or other non-standard methods.

The activities the report searches for are listed below, each of which requires students to take ‘actions’:



* Quiz
* Choice
* Feedback
* Chat
* Checklist
* Group choice
* H5P activity
* Questionnaire
* Workshop
* AI Feedback (LTI)
* EON-XR (LTI)
* LearnSci Resources (LTI)



In addition, the report searches for any activities with completion criteria, as these will similarly require certain actions from students. However, this is complicated by the fact that another minimum standard requires adding completion criteria to summative assessment. Summative assessment is largely an and-point process, so while it does require action from students it not always part of an active _learning_ process. In other words, adding completion criteria to a summative assessment link will not always indicate that active online learning is taking place on the course page. For this reason, this report **counts completion criteria as active learning if there are between 3 and 10 activities with completion criteria added**. The minimum of 3 reflects the assumption that completion criteria will already be added to summative assessment links. The maximum of 10 reflects the fact that there are some legacy course pages still regularly imported to current modules, where every activity has completion criteria added by default and without any real intention to use them for learning design or active learning.

If none of the listed activities are found on the course page, and there are no activities with completion criteria, then the report will show a warning for uses saying that there are “No active learning activities found in this course”:

### How to use it

By default your course page will not have any active learning activities on the course page. This report will therefore show a warning badge saying that “No active learning activities \[are] found in this course”. Underneath this warning is a list of the active learning activities that you could add to your course in order to meet the minimum standard:


![](/assets/gitbook/image-115.png)


Hovering your cursor over any of these activities will show a tooltip. This tooltip lists some of the ways in which the activity can be used in your course - for example, using the Feedback activities to support reflection, engagement and metacognition:


![](/assets/gitbook/image-116.png)


Below is the full list of all the activities, together with their associated tooltips:



* **Quiz:** Improves performance, retention, and conceptual understanding
* **Choice:** Increases engagement and encourages participation through decision-making
* **Feedback:** Supports reflection, engagement, and metacognition
* **Chat:** Supports discussion, engagement, and deeper thinking
* **Checklist:** Supports self-regulated learning, planning, and progress monitoring
* **Group choice:** Encourages participation, peer awareness, and collaborative decision-making
* **H5P activity:** Supports engagement, interaction, and conceptual understanding
* **Questionnaire:** Supports reflection, response, and learner self-awareness
* **Workshop:** Supports peer review, evaluation, and higher-order thinking
* **AI Feedback (LTI):** Supports timely personalised feedback and improved performance
* **EON-XR (LTI):** Supports immersive learning, engagement, and applied understanding
* **LearnSci Resources (LTI):** Supports conceptual understanding and improved performance through interactive learning resources



These tooltips are not definitive, as there are multiple options for different kinds of active learning activities within each of the resources. For example, inside of H5P there are a over 40 varieties of active learning activities, ranging from AR scavengers to interactive videos. Guides and demonstrations of every H5P activity can be found by clicking on [this link to the h5p website](https://h5p.org/content-types-and-applications).

When any active learning activity is added to your course page, that activity will appear in this report. The name of the activity will appear, together with the activity type and whether any completion criteria has been added to it. Clicking on the name of any activity will take you directly to that activity:


![](/assets/gitbook/image-117.png)


It is possible to **meet the minimum standard for active online learning using only activities with completion criteria** added to it. For example, you course may include none of the listed activities - but you may be set up completion criteria for a number of other activities that promote student engagement and direct action. However, because it is already expected that completion criteria will be added to summative assessments, the minimum standard will only be considered as met if there are at least 3 such activities with completion criteria. If there are, 3 or more activities with completion criteria added, then these activities will be listed in the report and a green tick will show in the ‘Completion criteria’ column:


![](/assets/gitbook/image-118.png)


Underneath your activities, there is a further list of active learning activities. This list shows only those active learning activities that are **not being used on your course**, and that you may want to add. By hovering your cursor over each of these activities, you will see a popup tooltip with ideas about the ways in which you can use the activity:


![](/assets/gitbook/image-119.png)
