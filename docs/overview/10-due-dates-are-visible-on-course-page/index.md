# 10 Due dates are visible on course page

One of the most important things students need to know is the due dates of any submissions for their module. For this reason, it is important to ensure that these dates are as visible as possible. Although dates are going to be included in Module Guides, it is not always easy for students to download and open these documents to search for them—especially if they are working through a mobile device. This minimum standard is designed to ensure that students can have confidence that the due dates for their submissions will be visible on their Moodle course page.

### Appearance

The top of the detailed report table explains the criteria through which the pass / fail result has been achieved on the summary report and in the progress bar. Below that explanation, there is a list of all the places on the course page where something looking like a due date has been identified:


![](/assets/gitbook/image-96.png)


On each row is the name of the activity or description that has been identified, together with a brief explanation of how that activity has been matched by the report.

### What it does

Ideally, due dates for assignments will appear in the same way across all course pages. This would make it predictable for students, and easy for a report to identify. However, the range of needs for each course page and the wide variety of different practices means that it would be difficult (and potentially limiting) to make this a minimum standard. Therefore, this report adopts a **very broad** approach to identifying whether due dates have been included on the page, which does increase the **possibilities of false positives** (i.e. any reference to a date in the name or description of an activity may lead to this condition being met, even if it is not an assignment due date).

The report scans the whole course page looking for any visible text in **activity names**, **section names** or **descriptions** that might be a due date. It searches for phrases such as _submission, due, due on, submission date, submit by, submit before, deadline, closing date, closes on, cutoff, cut-off, dates_. It looks as well for date patterns such as _4th November 2025_, _04/11/2025_ or _04-11-2025._

If no matching text is found in sections or activities that are visible to students, then a warning message will appear at the top of the report explaining that “There seems to be due date information on the course page, but it is not currently visible to students. Please add due date information, or unhide the existing information”:


![](/assets/gitbook/image-97.png)


If any matching text is found, and if the activity including the text is visible to students, then this minimum standard is considered met. If matching text is found on an activity that is **hidden from students**, this activity will show as greyed out and with a ‘hidden’ icon next to it. Hidden activities are not counted as meeting the minimum standard.

If matching text is found in an activity description, but that description is not visible on the course page, a warning symbol will appear in the activity match column. However, the match will still be considered as meeting the minimum standard.


![](/assets/gitbook/image-98.png)


### How to use it

This report will scan through your course page looking for any references to due dates for submissions. Any matching resource it finds is listed together with an explanation of why it has been matched. For example, a resource with the title ‘04-11-2025’ will be matched because it looks like a date.


![](/assets/gitbook/image-99.png)


A resource with the title ‘Late submission 14th Jan’ will be matched because it contains the word ‘submission’.


![](/assets/gitbook/image-100.png)


You need only 1 activity to be highlighted in green, with matching text, in order to meet the minimum standard. If you see an activity highlighted in grey, and with a ‘hidden eye’ icon next to the activity name, this indicates that that activity has been ‘hidden from students’. Activities that are hidden from students are not counted as meeting the minimum standard.


![](/assets/gitbook/image-101.png)


If there are no visible activities with a due date, a yellow warning message will appear at the top of the report saying “There seems to be due date information on the course page, but it is not currently visible to students. Please add due date information, or unhide the existing information”:


![](/assets/gitbook/image-102.png)


You can make activities visible by clicking on the name of the activity. This will take you directly to the position of the activity on your course page, and from here you can change the visibility settings to make it visible to students:


![](/assets/gitbook/image-103.png)


The text in the ‘matched phrase’ column shows you information about exactly why the activity has been identified by the report. Additionally, it tells you whether the matched phrase appears in the title of the activity or the description. For example, if the text in the matched phrase column says “Title contains the phrase ”submit before"", then you know that the text is in the title of the activity:


![](/assets/gitbook/image-104.png)



![](/assets/gitbook/image-105.png)


If you see a warning icon next to the matched phrase, this indicates that the text has been identified in the description of the activity, but that this description is not visible on the course page. In the example below, a quiz has been identified. The title of the quiz is ‘Test’, but the description of the activity contains a due date:


![](/assets/gitbook/image-106.png)



![](/assets/gitbook/image-107.png)


In the settings for the quiz, it is possible to see the text in the description reading “This test is due on 25th November”. Underneath the description is a tickbox for displaying the description on the course page:


![](/assets/gitbook/image-108.png)


When this box is ticked, the description text will appear on the course page along with the activity title:


![](/assets/gitbook/image-109.png)


Although it is not required to have this box ticked in order to meet this minimum standard, it is strongly encouraged that this is done if the description contains vital information for students such as due dates. This makes the information more easily and immediately visible for students.
