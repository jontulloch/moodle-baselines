# 07 Specific careers information

For students to fully engage with a module, they need to understand the value it gives them. Part of this involves making it explicit to students how each particular module will benefit their careers. As such, one of the minimum standards for Moodle pages is that they include some information in the Careers & Employability section that connects the learning outcomes and activities in the module to specific career benefits.

### Appearance

The top of the detailed report table explains the criteria through which the pass / fail result has been achieved on the summary report and the in the progress bar. Below that explanation, there is a single list of all activities on the course page which have been identified:


![](/assets/gitbook/image-58.png)


### What it does

The report looks on the module page for a section titled ‘Career & Employability’. This section is added by default to all new course pages when they are created, and it is into this section that careers information should be added. By default there is already some content in the career & employability section, and the report is pre-programmed to ignore this default content.


![](/assets/gitbook/image-59.png)


If there is only default content in the career & employability section, then the report will display a warning saying that ‘no resources have been added yet to the section’.


![](/assets/gitbook/image-60.png)


If resources have been added to the section, but are hidden from students, then another yellow warning will appear stating that there are no _visible_ resources. Underneath this, additional resources in the section will be listed, but greyed out and with a hidden eye icon. Clicking on the eye icon will toggle the resource to a ‘visible’ state.


![](/assets/gitbook/image-61.png)


If any resources have been added to the career & employability section, and they are visible to students, the report will list these resources in green to indicate that the conditions for the minimum standard have been met:


![](/assets/gitbook/image-62.png)


### How to use it

In order to meet the criteria for the minimum standard, the report needs to have no yellow warning messages. If there are no resources visible to students on the course page, a yellow warning message will appear.


![](/assets/gitbook/image-63.png)


If **no resources have been found**, there is a link in the description that will take users to an AI agent. This agent has been tailored specifically to meet the needs of UEL students, and by uploading a module guide, or module learning outcomes, it will automatically generate content that you can use as a basis for adding content to your career & employability section.

If content **is found in the career & employability section, but it is hidden from students**, there is a ‘hidden’ icon next to the activity name. Clicking on this will automatically make the activity ‘visible’ and redirect you to the course page with the newly visible activity showing.
