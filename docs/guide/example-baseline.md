# Example baseline

::: warning Example only
This page is a reusable structure for documenting a baseline. Replace the prompts below with your agreed requirements before using it as guidance.
:::

## Requirement

State the requirement clearly and explain who it applies to.

## Why it matters

Explain how the requirement helps students or staff.

## How to meet it

1. Describe the first action.
2. Explain the next action.
3. Describe what the completed result should look like.

## How to check it

Explain how someone can confirm the requirement has been met.

## Examples and further guidance

Add examples, screenshots with meaningful alternative text, or links to supporting information.
